# Product

## Register

product

## Users

Self-hosted image API operators, creators, and ecommerce users who need a compact workspace for generating, editing, reviewing, and reusing image outputs. They are usually in a task flow: upload references, choose a model and size, submit work, inspect results, and keep the exact product or account configuration under control.

## Product Purpose

GMKRAW provides a local image-generation API and web workspace for OpenAI-compatible image generation, image editing, account-pool management, and task history. Success means users can produce usable images quickly while retaining control over authentication, model routing, storage, and image fidelity.

## Brand Personality

Practical, technical, and composed. The interface should feel like a reliable production tool rather than a promotional website.

## Anti-references

Avoid marketing-page decoration, oversized hero layouts, ornamental motion, and controls that obscure the core workflow. Do not make ecommerce-preservation tools feel like a separate wizard when an inline mode can support the existing composer.

## Design Principles

- Preserve user intent before adding model creativity.
- Keep generation controls close to the prompt and reference images.
- Surface risk and tradeoffs in compact, actionable language.
- Favor predictable controls and dense but readable task layouts.
- Protect existing workflows by making specialized modes explicit and reversible.

## Accessibility & Inclusion

Target WCAG AA contrast and keyboard-accessible controls. Respect reduced-motion preferences and keep labels understandable for users comparing many tasks or results in one session.
