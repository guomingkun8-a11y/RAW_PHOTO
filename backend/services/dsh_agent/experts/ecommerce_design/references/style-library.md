# 电商构图与风格

按用途选择类型，再选风格与场景；参考仅控制表现方式，商品身份约束始终优先。以下为本项目原创的业务规则，不是第三方案例图库。

## 五种图片用途
- 主图：首屏快速识别商品，主体完整且占画面主要面积，背景与商品有清晰明度区分；文字少且层级明确，不遮挡标签和关键结构。
- 车图：淘宝商品轮播展示图，不是汽车图片。每张回答一个不同购买问题或展示一个已确认卖点，分配不同但协调的场景/视角；不要只换背景复制同一构图。
- 白底图：纯白背景，完整商品与正确数量，可有克制自然接触阴影；不加文字、标签贴纸、道具、边框或水印。不得清除原有商品包装标签。
- SKU 图：只呈现已确认的颜色、尺寸、型号和组合，清楚对应具体选项；不能为了丰富画面发明其他颜色、配件、规格。
- 标签图：突出已确认卖点，以主标题、证据/细节和商品三级组织信息，文字短、准确、可读；不编造功效，不遮盖商品原标签。

## 可选视觉方向
- 干净棚拍：中性背景、柔和主光、明确接触阴影，突出轮廓和真实材质；适合主图与白底图。
- 品牌编辑：继承已确认品牌色，留出文案区域，用克制的几何关系组织画面；适合主图和标签图。
- 真实使用场景：使用符合商品用途的环境与尺度，道具不抢主体；适合轮播图。不能凭场景暗示未证实功效。
- 细节证据：聚焦真实可见部件、质地和结构，不新增剖面或虚构内部功能。

## 整套协调
统一商品比例、品牌色、光线方向和视觉语言。先为每张分配目的与构图，再生成具体提示词；避免重复文案、重复视角、互相冲突的场景。用户没有要求套图时不擅自扩大为整套生成。比例、数量、质量、分辨率按实际所选模型白名单传入，不能只在提示词里写。
